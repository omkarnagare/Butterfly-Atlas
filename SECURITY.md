# Security

## Reporting a problem

Please report a security problem **privately**: on this repository's GitHub page, open **Security → Report a
vulnerability**. Do not open a public issue for it. Say what you found, the version of Butterfly Atlas, the operating
system, and the steps that show it.

## What counts

Butterfly Atlas is built to be reached only from the computer it runs on, and never to go online. A security problem is
anything that would let another program or another person, on the same computer or on the network, reach the app, its
library or its settings, or anything that makes the app send data anywhere.

## Supported versions

Only the latest release gets fixes.
